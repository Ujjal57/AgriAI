# INSTRUCTIONS TO FIX FARMER TOTAL DISPLAY

## Issue Verified ✅
- Backend API (/notifications/list) is correctly returning `farmer_total: "71504.00"`
- MySQL contract_b table has the correct value
- Frontend must be showing cached/stale data

## Solution: Clear Browser Cache

### Option 1: FULL CACHE CLEAR (Recommended)
1. Press **Ctrl + Shift + Delete** to open Clear Browsing Data
2. Select timeframe: **All Time**
3. Check these boxes:
   - ☑ Cookies and other site data
   - ☑ Cached images and files
4. Click **Clear data**

### Option 2: Hard Refresh (Quick)
After clearing cache OR if you want to try quick refresh first:
1. Press **Ctrl + F5** (Windows) or **Cmd + Shift + R** (Mac)
   - This does a hard refresh bypassing cache

### Option 3: Clear localStorage (AgriAI app data)
Open Browser Console (F12) → Console tab → Paste:
```javascript
// Clear AgriAI app localStorage
localStorage.removeItem('agriai_history_farmer');
localStorage.removeItem('agriai_notifications');
localStorage.clear(); // or just clear AgriAI keys
location.reload();
```

## What to Do:
1. Go to browser Developer Tools (F12)
2. Open Console tab
3. Paste the localStorage clearing code above
4. Or do Ctrl+Shift+Delete for full cache clear
5. Then hard refresh page (Ctrl+F5)
6. Go to Notifications page
7. Verify farmer amount shows ₹71,504.00 instead of ₹0
